# Проверка «Олли: Рамэн-чемпион!»

Дата: 9 ноября 2026 года. Публичная публикация не выполнялась.

## Автоматические проверки игровых правил

Команда: `node --test tests/engine.test.cjs` из папки игры.

Результат: **10 тестов из 10 прошли**, Node.js 24.22.1.

| Проверка | Подтверждённый результат |
| --- | --- |
| Все четыре уровня | На каждом создаются три полные миски и работает отсчёт 3 секунды |
| Отдельные нажатия | Несколько нажатий в одном кадре учитываются все, без потери порций |
| Самостоятельные соперники | Котик и цыплёнок едят без ввода игрока и с разным ритмом |
| Количество лапши | Каждая принятая порция уменьшает `remaining`, до нуля |
| Обязательный бульон | Нулевая лапша не даёт мгновенную победу; требуется ещё 2,8 секунды питья |
| Победа игрока | На каждом уровне темп 2,5 нажатия/сек приводит к победе за ~42,8 секунды |
| Победа соперника | Без нажатий соперник побеждает примерно за 66 / 60 / 56 / 51 секунду |
| Пауза | Не движутся отсчёт, гонка, анимационный таймер и этап питья |
| Частота кадров | Крупные и мелкие шаги времени дают тот же итог и время финиша |
| Ничья и повтор | Одновременный финиш отдаёт победу Олли; перезапуск сбрасывает состояние |

Значения длительности измерены с фиксированной случайностью для воспроизводимости. В обычной игре небольшое изменение ритма соперников намеренное.

## Проверка интерфейса в браузере

Игра запущена в изолированном Chrome 157.0.8103.38 через Playwright, напрямую из `index.html` (`file://`). Файл проверки: `tests/browser.test.cjs`. Проверены реальные обработчики интерфейса; правила гонки не подменялись. Для ожидания поражения использованы управляемые часы тестового браузера.

| Проверка | Фактический результат |
| --- | --- |
| Загрузка без сервера | Главная страница и все шесть SVG-слоёв загружаются из локальной папки |
| E, пробел, мышь, «НЯМ!» | Четыре действия дали ровно четыре порции; повтор удерживаемой клавиши не добавляет лишнюю порцию |
| Соперники | У обоих количество съеденных порций растёт без действий игрока |
| Пауза | Время и количество порций остаются неизменными; продолжение работает |
| Четыре уровня | На каждом введено 100 отдельных нажатий, показано питьё, зарегистрирована победа, открыт следующий уровень |
| Доброжелательное поражение | Без нажатий побеждает соперник; показан экран результата и работает повтор |
| Сохранение | После перезагрузки доступны четыре открытых уровня; настройки музыки и эффектов сохраняются независимо |
| Звук после действия | До старта AudioContext не существует; после нажатия запуска имеет состояние `running` |
| Мобильный ввод | Два сенсорных нажатия дали ровно две порции |
| Размеры экрана | На ширинах 320, 390, 768, 1024 и 1440 px нет горизонтального переполнения |
| Результаты | Проверены переходы, повтор и возврат к уровням после победы |
| Ошибки исполнения | Необработанных ошибок JavaScript, ошибок консоли и ошибок загрузки ресурсов не обнаружено |

Снимки находятся в `docs/screenshots/`: главная страница, настольная и мобильная сцены, питьё и победа каждого уровня, дружеское поражение. Снимки просмотрены: видны три героя с признаками исходного образца, глубокие миски, разные фоны, поднятая золотая миска и улыбающиеся друзья.

Победы в браузерном тесте достигаются быстрыми тестовыми нажатиями, поэтому время на снимках короче обычного раунда. Типичные 40–70 секунд подтверждены отдельными тестами при человеческом темпе нажатий.

## Проверка звукового движка

`tests/audio.test.cjs`: **7 из 7 тестов прошли**. Проверены ограничение наложения при 100 быстрых нажатиях, освобождение звуковых узлов, независимое отключение музыки и эффектов, пауза и возобновление, восстановление после прерывания аудиоконтекста, отсутствие накопленной очереди нот и завершение звукового движка во время запуска. Это программная проверка; субъективная оценка звучания через динамики разных устройств не выполнялась.

## Покадровая проверка анимации

`node tests/art.test.cjs` — пройдена в отдельном Chrome. Для каждого из трёх персонажей сравниваются настоящие кадры Canvas: захват и подъём лапши, втягивание, мимика, полная/половинная/пустая миска, подъём для питья и возвращение на стол. Дополнительно проверены конфетти и движущиеся хлопки/награда при обычном режиме анимации.

Все проверки прошли. Во время движения рук изменяется более 3 000 пикселей у каждого героя, а в пустых мисках не обнаружено пикселей лапши. Возвращённая миска точно совпадает с её положением на столе. Итоговый контактный лист `screenshots/animation-phases.png` также просмотрен вручную.

В этой проверке SVG загружаются из тех же исходных байтов как встроенные изображения, чтобы браузер разрешал анализ пикселей локального файла. Рабочая версия игры загружает исходные SVG-файлы обычным способом; настройки защиты браузера не менялись.

## Обновление 1.0.1: полный экран

`node tests/fullscreen.test.cjs` — пройдена проверка настоящего Fullscreen API в отдельном Chrome: вход и выход на главном экране и во время гонки, синхронизация кнопки при внешнем выходе, сохранение игрового состояния, отсутствие горизонтальной прокрутки при ширине 320 px. В полном экране сцена и кнопка еды помещаются в 1440×900 и 844×390. Неподдерживаемый или запрещённый API показывает сообщение, после которого можно продолжить играть. Снимки: `screenshots/fullscreen-desktop.png` и `screenshots/fullscreen-landscape.png`.

На кнопке полного экрана также проверены Enter и пробел: они переключают режим без лишних съеденных порций.
