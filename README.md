# Олли: Рамэн-чемпион!

Уютная браузерная игра для детей: Олли, белый котик и жёлтый цыплёнок соревнуются за столом с рамэном. Четыре уровня, отдельные движения персонажей, оригинальная музыка, сохранение прогресса и большая кнопка «НЯМ!».

Проект работает без регистрации, платных API, сторонних библиотек и серверной части. Публичная публикация не выполнялась.

## Быстрый запуск на компьютере

1. Распакуйте архив проекта в отдельную папку, сохранив все вложенные папки.
2. Откройте `index.html` двойным щелчком в современном браузере.
3. Нажмите «Давай играть!». Музыка включается только после действия пользователя.

Установка программ для этого способа не нужна. Код, изображения и звуки находятся в папке игры; внешние загрузки не требуются.

Если Node.js уже установлен, можно запустить локальный просмотр из папки проекта:

```sh
npm start
```

Или без npm:

```sh
node serve.cjs
```

Затем откройте [игру на этом компьютере](http://127.0.0.1:4173). Сервер просмотра доступен только на этом компьютере. Для остановки нажмите `Ctrl+C` в его окне.

## Как играть

- Дождитесь обратного отсчёта «3, 2, 1 — ЕДИ!».
- Нажимайте `E`, пробел, левую кнопку мыши по игровому полю или кнопку «НЯМ!».
- Каждое отдельное нажатие съедает одну порцию. Удерживать клавишу не нужно.
- Котик и цыплёнок едят самостоятельно и с разным ритмом.
- После лапши Олли сама поднимает миску и допивает бульон. Это занимает 2,8 секунды; нажимать в этот момент не требуется.
- Побеждает первый, кто полностью закончил и лапшу, и бульон.
- Кнопка паузы, `P` или `Esc` останавливает раунд. При переключении на другую вкладку раунд тоже ставится на паузу.
- Кнопка с четырьмя уголками вверху справа включает полный экран. Повторное нажатие возвращает обычный вид. В полном экране `Esc` служит для выхода, а `P` по-прежнему ставит игру на паузу. Если браузер не поддерживает этот режим или запрещает его, появится понятное сообщение; игра продолжит работать.

Обычный раунд длится примерно 40–70 секунд. Около двух–трёх отдельных нажатий в секунду достаточно для игры; на последних уровнях соперники быстрее. Проигрыш не отнимает открытые уровни — можно сразу попробовать ещё раз.

## Четыре приключения

| Уровень | Место | Награда за победу |
| --- | --- | --- |
| 1 | Домашний рамэн: солнечная кухня | Открывается японская рамэнная |
| 2 | Японская рамэнная: дерево и фонарики | Открывается кафе под сакурой |
| 3 | Рамэн под сакурой: цветы за окном | Открывается фестиваль |
| 4 | Фестиваль рамэна: вечерняя японская улочка | Золотая миска и праздник |

На главном экране можно повторно запустить любой открытый уровень. Прогресс и две настройки звука сохраняются в этом браузере на этом устройстве. Если очистить данные сайта или использовать приватный режим, сохранение может исчезнуть. Перенос игры на другой адрес создаёт отдельное сохранение.

Музыка и эффекты отключаются независимо: кнопка динамика вверху → «Музыка в кафе» / «Весёлые звуки». Игра остаётся полностью доступной без звука.

## Телефон

Интерфейс подстраивается под узкий экран: три соперника остаются видны вместе, а кнопка «НЯМ!» расположена под сценой. Нажимайте её пальцем; удерживание не заменяет отдельные нажатия. После размещения игры открывайте её HTTPS-ссылку в браузере Android или iPhone.

Результаты проверок и ограничения испытаний перечислены в [docs/QA.md](docs/QA.md). Проверка на реальных телефонах отдельно не проводилась; эмуляция размера экрана не является такой проверкой.

## Размещение на GitHub Pages

Эти действия выполняются владельцем только тогда, когда он решит опубликовать игру. Никакой удалённый репозиторий или сайт в рамках подготовки проекта не создан.

1. Создайте отдельный репозиторий GitHub для игры.
2. Поместите **содержимое этой папки** в корень репозитория: `index.html` должен оказаться на верхнем уровне, рядом с `style.css`, файлами `.js` и папкой `assets`. Сохраните пустой файл `.nojekyll`.
3. В репозитории откройте **Settings → Pages**.
4. В **Build and deployment → Source** выберите **Deploy from a branch**.
5. Выберите ветку с файлами игры, обычно `main`, и папку **/(root)**. Нажмите **Save**.
6. После завершения публикации GitHub покажет адрес сайта в том же разделе Pages. Откройте его на компьютере и телефоне.

Сборка и переменные окружения не нужны. Относительные пути к ресурсам позволяют игре работать и по адресу вида `имя.github.io/название-репозитория/`. Порядок настройки проверен по [официальной инструкции GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Что находится в проекте

| Файл или папка | Назначение |
| --- | --- |
| `index.html`, `style.css` | Экраны, кнопки, адаптивное оформление |
| `app.js` | Управление, локальные сохранения, меню, связь звука и сцены |
| `engine.js` | Правила гонки, соперники, обратный отсчёт и питьё бульона |
| `art.js` | Рисование четырёх сцен и фаз анимации |
| `assets/*-head.svg`, `assets/*-body.svg` | Отдельные векторные слои персонажей |
| `assets/reference.png` | Предоставленная пользователем иллюстрация, также показанная на стартовом экране |
| `audio.js` | Оригинальная партитура и синтез звуков в браузере |
| `assets/audio/` | Готовая музыкальная петля и эффекты WAV, воспроизводимый генератор |
| `audio-source.md` | Сведения о музыке, эффектах и аудиоресурсах |
| `tests/engine.test.cjs` | Автоматические проверки игровых правил |
| `tests/browser.test.cjs` | Проверки управления, прохождения, сохранений и мобильного интерфейса в Chrome |
| `tests/art.test.cjs`, `tests/audio.test.cjs` | Проверки реальных кадров анимации и звукового движка |
| `serve.cjs` | Необязательный локальный сервер для просмотра |
| `docs/QA.md` | Результаты проверки и известные ограничения |

Персонажи адаптированы из исходной иллюстрации в векторные слои. Двигаются отдельные руки и лапки, палочки, лапша, мимика и миски; вся картинка целиком не используется как заменитель анимации. Векторная версия сохраняет узнаваемые признаки героев, но не воспроизводит исходную рисованную текстуру пиксель в пиксель.

## Музыка и материалы

**Little Bowl Café** — оригинальная инструментальная композиция, 100 BPM: мягкое электропиано, лёгкая мелодия, бас и тихая ритмическая партия. В ней нет вокала, чужих песен и сторонних семплов. Игра синтезирует музыку и эффекты через Web Audio API; готовые WAV-файлы включены для прослушивания и дальнейшего использования. Подробнее — [audio-source.md](audio-source.md).

Исходная иллюстрация предоставлена пользователем. Права на неё остаются у её правообладателя; этот проект не предоставляет отдельную лицензию на исходное изображение. Новые слои персонажей являются адаптацией этого образца. Звуки и партитура созданы специально для игры и доступны для использования с проектом без платы.

## Проверка и доработка

Для запуска тестов при установленном Node.js:

```sh
npm test
```

Или:

```sh
node --test tests/engine.test.cjs tests/audio.test.cjs
```

Для повторного создания файлов WAV:

```sh
node assets/audio/render-audio.cjs
```

Игра не требует `npm install`. Все четыре уровня настроены в массиве `LEVELS` файла `engine.js`; там можно изменить скорость соперников и количество порций.

Для повторения браузерных проверок разработчику нужны Chrome и пакет Playwright: `npm install --no-save playwright`, затем `node tests/browser.test.cjs`. Они нужны только для проверки, не для игры или GitHub Pages. Проверка использует отдельный профиль браузера и не затрагивает ваши обычные вкладки или игровые сохранения.

Проверка кадров анимации запускается командой `node tests/art.test.cjs`. Все фактические результаты перечислены в `docs/QA.md`; снимки сохраняются в `docs/screenshots/`.
